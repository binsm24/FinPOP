# 시작 화면

`feature/splash/SplashScreen.kt`는 Stitch의 시작 화면 HTML/SVG를 Compose Canvas로 옮긴 앱 내부 인트로다. Android 시스템 시작 화면 뒤에 표시된다.

- 파랑/연보라 6줄 팝콘 통, 금색 동전, 눈 달린 로고, 슬로건 배지를 그린다.
- 동전 부유 주기는 4.2초/3.5초, 별 반짝임은 2.8초, 배지 점은 2초 주기로 반복한다.
- HTML에는 입장 문구만 있고 실제 이동 코드는 없다. 앱에서는 화면 탭 또는 3초 대기 후 로그인 화면으로 이동하도록 정의했다. 시간은 `autoEnterMillis`로 바꿀 수 있다.
- MainActivity에서 350ms Crossfade로 로그인으로 전환한다. Activity를 새로 생성하거나 백그라운드에서 복귀하면 인트로를 다시 표시한다. 화면 회전으로 Activity가 재생성되는 경우에도 다시 표시한다. 앱이 배경으로 가면 자동 이동 타이머를 취소하고 복귀 시 새 화면에서 3초를 다시 센다.
- 실제 인증이나 계정 복원은 수행하지 않는다.
- 웹의 가짜 시계/배터리/홈바는 그리지 않는다. Android 시스템 UI를 사용하고 하단 안내는 내비게이션 바 위에 배치한다.
- 로고 글꼴은 제공된 웹 폰트 파일이 없어 시스템 rounded/bold로 대체했다.
